This is a fireclassification dataset with YOLOV8 format

We divide fires into 6 categories to help firefighters get fire details faster.[Forestfire、Indoorfire、Electricalfire、Buildingfire、Vehiclefire、Grassfire]


forestfire: forestfire;

indoorfire: fire inside buildings

Electricalfire: Fire caused by electrical appliances

Buildingfire: Fire throughout the whole building

Vehiclefire：Fire caused by Vehicle

Grassfire：fire on the grass


hope this dataset can help you.
